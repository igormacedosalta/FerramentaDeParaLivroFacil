Base de dados — enviar planilha

Suba aqui uma planilha (.xlsx ou .csv) com as colunas Marca, Unidade, Turma, Turno, ISBN, DESCRICAO para substituir por completo a regra geral, as unidades e as exceções das marcas presentes no arquivo. A ferramenta calcula sozinha: o que é igual em todas as unidades de uma série/turno vira regra geral; o que só existe em algumas unidades vira exceção. Use isso para uma recarga completa da base (ex.: início de um novo ciclo). Para ajustes do dia a dia, use as abas Regra geral / Exceções / Novas unidades.

Acessos — diretores por marca

Cadastre aqui o e-mail de cada diretor e quais marcas ele pode ver e editar. Depois de cadastrado, o diretor acessa a ferramenta com esse e-mail e cria a própria senha na tela de login ("Primeiro acesso? Criar senha"). Um diretor pode ter mais de uma marca.
